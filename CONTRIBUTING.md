# Contributing

This is for changing the platform itself. To write an app with it, see the
[README](README.md) instead: an app needs no checkout.

Contributor guidance is in the manual:
[Contributing](docs/contributing.adoc) covers building the platform from a
checkout, running the examples, the check gate, the bundle, the `macos.roc`
tool and releasing, and [Architecture](docs/architecture.adoc) explains how
the engine, the Swift host, the glue and the linker inputs fit together.
[AGENTS.md](AGENTS.md) has the rules every change follows.

Use issues for bug reports and design discussion, and pull requests for
changes. Report vulnerabilities as [SECURITY.md](SECURITY.md) describes.
