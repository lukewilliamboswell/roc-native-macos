= roc-native-macos
:doctype: book
:toc: left
:toclevels: 2

roc-native-macos is a new Roc platform for native Mac apps. The
roc-signals engine updates AppKit controls through a Swift host.

App authors can create and run a project from a release. Start with
xref:apps.adoc#get-started[Build an app] and look up controls in
xref:ui.adoc#builders[the Ui reference].

Contributors can build the platform from a checkout. Start with
xref:contributing.adoc#build-the-platform[Contributing] and read
xref:architecture.adoc#how-it-fits-together[Architecture] for the design.
